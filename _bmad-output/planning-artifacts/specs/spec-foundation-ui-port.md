# Engineering Spec - Epic 01: Foundation and exact UI port

## Contract sources

PRD, architecture, DATA_MODEL, `engineering/VISUAL-PORT.md`, `AGENTS.md`, and live Superdesign.

## Stories

01-01 through 01-06.

## Implementation rule

Implement story-by-story. The live Superdesign project is primary. V4/V2 screenshots are regression evidence. Missing required visual states are created/iterated in the same Superdesign project first. The initial styling stack must match the live design's Tailwind major rather than force a migration.

## Epic exit criteria

Approved routes/states are visually faithful with deterministic fixtures, build/lint/type checks pass, and visual baselines are committed/reviewed.
