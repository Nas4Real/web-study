# Product Brief - Web Study V4

## Product

Web Study is a private multi-user desktop web workspace for organizing academic tasks, study/calendar sessions, subjects and course files.

## Problem

Students often split active study information across calendars, task managers and local/cloud folders. Web Study puts the operational study workflow in one subject-centered workspace.

## V1 outcome

A user can authenticate, manage subjects, create/complete detailed tasks with subtasks, manage one-time/recurring sessions, inspect task/session details from context, organize private files, receive in-app reminders, manage settings/storage, and integrate external tools through a personal API.

## Principles

- private by default
- desktop-first
- live Superdesign is preserved, not redesigned by coding agents
- subjects connect tasks, sessions and documents
- canonical detail state is shared across list/dashboard/calendar launch surfaces
- file bytes stay private in object storage
- external automation uses a versioned API over the same services
- AI is deferred

## Exclusions

Native mobile, dedicated mobile redesign, Google Drive sync, cross-user sharing/collaboration, Apple login, AI Suggestion/document summaries, email/push notifications.

## Success criteria

Secure auth and tenant isolation; exact approved UI; task/session detail flows remain synchronized across surfaces; recurrence behaves correctly; files upload directly to R2; public API remains user-scoped; automated + visual tests prove behavior before release.
