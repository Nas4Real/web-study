# Epic 05: Documents folders and R2 storage

## Objective

Deliver documents folders and r2 storage as a cohesive vertical engineering milestone while preserving all cross-cutting security and design contracts.

## Stories

- 05-01: Chapters and hierarchical folders
- 05-02: R2 client private bucket configuration
- 05-03: Atomic quota reservation and upload intents
- 05-04: Upload completion verification and cleanup
- 05-05: Documents UI search sort recent and navigation

## Exit criteria

- all stories complete, with Superdesign-first states created before their code
- ready-superdesign-first stories begin with a live Superdesign draft step rather than direct code invention
- unit/integration/E2E tests for this epic pass
- RLS/security checks pass for new user data
- UI changes match approved Superdesign baselines
- architecture decisions and schema changes are reflected in documentation
