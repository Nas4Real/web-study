# Epic 03 - Tasks, Detail Views and Dashboard

## Outcome

Canonical task domain powers Tasks and Dashboard, including priority, descriptions, subtasks and approved Task Details.

## Stories

- 03-01 Tasks schema/service/CRUD with priority + description foundation
- 03-02 Wire existing New Task/list UI to TaskService
- 03-03 Dashboard derived queries
- 03-04 Task Details modal and subtask interactions
- 03-05 Enrich New/Edit Task authoring in Superdesign then implement priority/description/subtasks

## Dependencies

Epic 01 UI foundation; Epic 02 auth/subjects.

## Exit gate

Task details work from supported surfaces; subtasks are secure/independent; dashboard stays synchronized; approved visuals and E2E/RLS tests pass.
