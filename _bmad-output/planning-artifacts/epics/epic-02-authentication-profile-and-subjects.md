# Epic 02: Authentication profile and subjects

## Objective

Deliver authentication profile and subjects as a cohesive vertical engineering milestone while preserving all cross-cutting security and design contracts.

## Stories

- 02-01: Supabase SSR clients and protected routing
- 02-02: Email signup verification signin and Google OAuth
- 02-03: Forgot/reset password flow
- 02-04: Profile subject and avatar domain
- 02-05: Email verification result UI
- 02-06: Set-new-password UI

## Exit criteria

- all stories complete, with Superdesign-first states created before their code
- ready-superdesign-first stories begin with a live Superdesign draft step rather than direct code invention
- unit/integration/E2E tests for this epic pass
- RLS/security checks pass for new user data
- UI changes match approved Superdesign baselines
- architecture decisions and schema changes are reflected in documentation
