# Epic 06: Notifications and settings

## Objective

Deliver notifications and settings as a cohesive vertical engineering milestone while preserving all cross-cutting security and design contracts.

## Stories

- 06-01: Notification preferences and generation backend
- 06-02: Wire notification bell/list
- 06-03: Wire Settings profile password storage signout
- 06-04: Notification preferences UI
- 06-05: Account deletion orchestration
- 06-06: Delete-account confirmation UI

## Exit criteria

- all stories complete, with Superdesign-first states created before their code
- ready-superdesign-first stories begin with a live Superdesign draft step rather than direct code invention
- unit/integration/E2E tests for this epic pass
- RLS/security checks pass for new user data
- UI changes match approved Superdesign baselines
- architecture decisions and schema changes are reflected in documentation
