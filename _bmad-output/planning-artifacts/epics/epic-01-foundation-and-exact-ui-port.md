# Epic 01 - Foundation and exact live-Superdesign UI port

## Objective

Create the application foundation and a deterministic, pixel-faithful React/Next.js implementation of currently approved live Superdesign states before real backend wiring.

## Stories

- 01-01 Bootstrap exact stack and quality gates
- 01-02 Establish live design references and deterministic fixtures
- 01-03 Port application shell and Dashboard pixel-faithfully
- 01-04 Port Calendar Day/Week/Month static views
- 01-05 Port Tasks, Documents, Settings and approved modals
- 01-06 Port auth screens with V1 provider correction

## Exit criteria

Live Superdesign was inspected for target states, Tailwind styling compatibility was pinned, visual baselines are reviewed, no missing state was invented in code, and quality checks pass.
