# End-to-End Test Specification V4

## Critical journeys

- E2E-001 sign up -> verify -> sign in -> dashboard.
- E2E-002 Google sign in -> dashboard -> sign out.
- E2E-003 create subject -> create task -> Task Details -> toggle subtask -> complete parent with another subtask incomplete -> Completed -> reopen.
- E2E-004 open Task Details from Tasks and supported Dashboard task surface; checkbox click does not also open modal.
- E2E-005 create Exam session -> visible in Day/Week/Month/dashboard derived data.
- E2E-006 create recurring University session -> open Session Details from Day/Week/Dashboard -> edit one occurrence -> verify detail override and unaffected sibling occurrence.
- E2E-007 recurring session delete chooses one occurrence and leaves series; whole-series delete removes all generated instances.
- E2E-008 upload document -> recent/all files -> download -> move -> delete.
- E2E-009 update profile -> password change -> sign in with new password.
- E2E-010 notification -> mark read -> deep-link to task/session detail.
- E2E-011 create API key -> API mutation/read -> revoke -> subsequent request fails.
- E2E-012 delete account -> cleanup -> old session cannot access app.

Use deterministic users, timezones, seeded timestamps and isolated test data.
